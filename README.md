# Novel cover asset

`novel-cover-sc-20261014.jpg` is the Simplified Chinese cover for
《毒茶入喉？老娘一鼻子闻翻将军府》.

Illustration: AI-generated fictional character artwork based on the selected
project character design. It is not a photograph of a real person.

Typography: Adobe Source Han Serif CN Heavy (思源宋体), official release 2.003.
All cover text was manually typeset using the actual font file.

Official font source:
https://github.com/adobe-fonts/source-han-serif/tree/release/SubsetOTF/CN

Font license: SIL Open Font License 1.1.
